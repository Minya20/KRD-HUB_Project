# KRD Project Hub — 국가 연구과제 관리 플랫폼

> 개발자 양성과정 1차 팀 프로젝트 · Pure Java 콘솔 애플리케이션 (4인 팀)

국가 R&D 과제의 전체 생애주기(공고 → 지원 → 선정 → 과제 수행 → 보고 → 예산 집행 → 평가)를
콘솔 환경에서 관리하는 시스템입니다. 프레임워크 없이 **순수 Java + JDBC**만으로
DAO/VO/Service 계층 구조를 직접 설계하여, 이후 JSP/Servlet → Spring Boot 학습의
기반을 다지는 것을 목표로 한 프로젝트입니다.

## 주요 기능

| 도메인 | 기능 |
|---|---|
| 회원 / 권한 | 회원가입, 로그인, 역할 기반 메뉴 분기 (관리자 ADM · 기관 담당자 AGY · 책임연구원 RESO · 연구원 RESI · 평가위원 REV · 게스트 GST), 권한 신청/승인 |
| 공고 관리 | 연구과제 공고 등록/조회/상태 관리 (모집중/마감 등) |
| 지원 / 선정 | 공고 지원 접수, 지원자 검토, 과제 선정 처리 |
| 과제 수행 | 과제(Task) 진행률 관리, 팀 단위 진척도 조회 |
| 보고서 | 단계별 연구 보고서 제출/조회 |
| 예산 / 자금 | 예산 배정, 집행 내역(Budget History) 관리, 사용 현황 요약 |
| 평가 | 평가위원의 과제 평가 처리 |
| 통계 | 기관별/연도별 과제 현황 통계 조회 |

## 기술 스택

- **Language**: Java (JDK 17)
- **Database**: Oracle (JDBC — ojdbc8, `DBUtil` 커넥션 유틸 직접 구현)
- **UI**: 콘솔 기반 — ANSI Escape Code를 활용한 컬러/볼드 출력, 박스 드로잉 문자로 메뉴 UI 구성
- **IDE**: Eclipse

## 아키텍처

프레임워크 없이 계층형 구조를 직접 설계했습니다.

```
src/kr/
├── util/         # DBUtil (JDBC 커넥션/자원 정리), 콘솔 출력 유틸
└── krd/
    ├── main/     # 역할별 메뉴 진입점 (콘솔 UI, 입력 처리)
    ├── service/  # 비즈니스 로직
    ├── dao/      # JDBC 기반 데이터 접근 (PreparedStatement)
    ├── vo/       # 데이터 전달 객체
    └── constant/ # 공고 상태, 보고서/자금 관련 상수
```

- 파일명 접두어(`CMY_`, `HYJ_`, `RR_`, `USH_`)는 팀원별 담당 모듈 구분입니다.
- 모든 SQL은 `PreparedStatement` 기반으로 작성해 파라미터 바인딩을 적용했습니다.

## 실행 방법

1. Oracle DB 접속 정보를 `src/kr/util/DBUtil.java`에 설정
2. `libs/ojdbc8.jar`를 빌드 패스에 추가
3. `kr.krd.main.UserMain` 실행 (일반 사용자) 또는 관리자용 Main 클래스 실행
